# Debuggers UTN · Cuarto semestre

Somos Debuggers UTN. En este repo fuimos subiendo los ejercicios y proyectos que trabajamos durante el cuarto semestre de la UTN.

## Qué hay en el repo

Hay carpetas por clase y otras dedicadas a proyectos que seguimos en varios encuentros. Si querés recorrer el código, podés empezar por acá.

- **Python** — prácticas de Python en un entorno profesional. [Ver ejercicios](Clase%2004%20-%20Python%20en%20Entorno%20Profesional%20-%20Parte%203/py-project)
- **Java** — ejercicios y proyectos como el Sistema de Estudiantes con Spring. [Ver proyecto](Sistemas%20Estudiantes%20Spring)
- **JavaScript** — ejercicios de desarrollo web, entre ellos un e-commerce básico. [Ver proyecto](Clase%2003%20E-commerce%20B%C3%A1sico%20Parte%2003/E-commerce)
- **Node.js** — prácticas de asincronía, callbacks y promesas. [Ver práctica de asincronía](Clase%2005%20%20Ejecutamos%20viendo%20la%20asincron%C3%ADa%20de%20Node)

## Cómo nos organizamos

Las consignas fueron saliendo clase por clase. Dejamos las actividades en issues separadas y cada integrante resolvió por su cuenta las que le tocaron. Así, cuando retomábamos un ejercicio, teníamos a mano la consigna y sabíamos de qué clase era. [Ver las issues del semestre](https://github.com/HotCode2025/DebuggersUTN-Cuarto-Semestre/issues)

## Para bajar los ejercicios

```bash
git clone https://github.com/HotCode2025/DebuggersUTN-Cuarto-Semestre.git
cd DebuggersUTN-Cuarto-Semestre
```

Para probar una actividad, entrá en su carpeta. Según el ejercicio, vas a necesitar Python, un JDK para Java, Node.js o un navegador para las prácticas web.
